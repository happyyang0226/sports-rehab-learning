# 스포츠재활총론

24개 장의 문제 풀이, 상세 해설과 오답 심화학습 웹앱입니다.

## 실행·배포

Node.js 22 이상에서 `npm ci` 후 `.env.example`을 `.env.local`로 복사하고 Supabase URL·publishable key를 설정합니다. `npm test`와 `npm run build`를 실행합니다. 정적 결과물은 `dist/`입니다. Vercel은 저장소 루트의 `vercel.json`을 사용합니다.

## 클라우드 학습 기록

로그인한 학생의 답안·확신도·변형 확인·오답 심화학습·자기 설명과 연습 점수를 Supabase에 장별 저장합니다. 본시험 점수는 클라이언트 연습용 요약이며 검증된 국가고시 점수가 아닙니다. 비로그인 기록은 해당 기기에 보관하며 로그인 전 기록 가져오기는 명시적으로 선택해야 합니다. 계정별 로컬 캐시와 서버 RLS로 다른 학생 기록을 구분합니다. 네트워크가 끊기면 로컬 변경을 보관하고 재연결 시 동기화합니다. 다른 기기의 최신 기록과 충돌하면 두 버전을 자동으로 덮어쓰지 않고 사용자가 선택합니다.

테이블·RLS·저장 함수 정의는 `supabase/schema.sql`입니다. 해당 Supabase 프로젝트에 한 번 적용합니다. 서버 함수는 SECURITY INVOKER이며 authenticated 사용자 본인 행만 처리합니다. service_role/secret key를 프런트엔드에 넣지 않습니다.

## Supabase Auth

이메일·비밀번호 가입과 로그인을 제공합니다. 두 앱은 같은 Supabase 프로젝트의 계정을 사용할 수 있으나 각 주소에서 로그인해야 합니다. 확인 메일·비밀번호 재설정 링크 사용을 위해 Supabase Auth의 Redirect URLs에 배포 주소를 등록하세요. 기존 프로젝트의 메일 인증 설정은 이 변경에서 수정하지 않았습니다.

## 기존 Sites 앱과의 관계

기존 ChatGPT Sites 앱은 유지합니다. 브라우저 저장은 주소별로 분리되므로 이전 Sites 주소의 로컬 기록은 새 Vercel 주소로 자동 이전되지 않습니다. 이 저장소에는 학생의 실제 기록이나 비밀번호, 서버 비밀키를 포함하지 않습니다.

## 콘텐츠

제공된 목차·학습목표 기반의 창작 학습 문항입니다. 교재 본문 대조 검토는 별도로 필요합니다. 기존의 전체 제출 후 해설 공개, 선택지별 풀이, 변형 확인과 네 단계 오답 심화학습을 유지합니다.
